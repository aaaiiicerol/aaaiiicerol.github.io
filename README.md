# aaaiiicerol.github.io

Site pessoal do **Aaaiiicerol**, publicado via GitHub Pages na raiz:
**https://aaaiiicerol.github.io/**

O conteúdo do site está na pasta `docs/` (padrão do GitHub Pages) e as imagens
em `assets/` (o workflow copia para `docs/assets/` antes do deploy).

## Estrutura
- `docs/index.html` — página inicial
- `docs/projects/` — uma página por projeto
- `assets/` — imagens (avatar e screenshots)
- `.github/workflows/pages.yml` — deploy automático no Pages

## Como publicar alterações
Basta commitar e dar push na branch `main` — o workflow `pages.yml` publica sozinho.
