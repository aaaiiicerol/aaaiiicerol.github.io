🎵 Zek Music

Player leve onde cada pasta vira uma playlist

Rust egui AppImage .deb .rpm Linux Windows 🟦 Microsoft Store MIT

📦 Instalação

  • 🟦 Microsoft Store (Windows)
  • Ver última release no GitHub
  • Linux: AppImage, .deb ou .rpm
  • AppImage: chmod +x ZekMusic-*.AppImage && ./ZekMusic-*.AppImage
  • Windows: instalador (ZekMusic-Setup.exe) ou versão portátil (.zip)

🔗 Links

  • Repositório no GitHub

  • Formatos: MP3, FLAC, OGG, WAV, M4A, AAC

✨ Funcionalidades

📁

Pastas = playlists

Cada pasta com músicas vira uma playlist com o nome da pasta. Sem importar nada, sem banco de dados.

💾

Não perde playlists

Se o disco não estiver montado ao abrir, o programa guarda tudo e avisa "pasta indisponível" — e volta sozinho quando montar.

🔢

Ordem que faz sentido

"2 - música" vem antes de "10 - música"; segue a numeração das tags do álbum quando existir.

🔄

Biblioteca viva

A pasta é monitorada: adicionou ou removeu um arquivo, o player atualiza sozinho.

✏️

Organize do seu jeito

Renomeie playlists (duplo clique), arraste para reordenar, crie playlists personalizadas e arraste arquivos para a janela.

⏯

Continua de onde parou

Ao abrir, volta para a última playlist, música e posição — e lembra volume, aleatório e repetir.

🖼️

Capas e tags

Capa do álbum, artista e duração lidos das tags, decodificados em segundo plano (trocar de música não engasga).

🎨

Visual e cor de destaque

Tema escuro moderno, 8 cores de destaque (ou uma cor sua) e tela "Tocando agora" com degradê na cor da capa.

⌨️

Teclas de mídia (MPRIS)

Play/pause, próxima e anterior do teclado funcionam mesmo com o app em segundo plano ou dentro de um jogo.

🔔

Aviso de atualização

Consulta o GitHub 1x por dia e avisa quando sair release nova. Erros ficam registrados em zek-music.log.

💪

Tolerante com arquivos

MP3 com ID3 fora do padrão ou cortados são recuperados automaticamente.

💻

Nativo e leve

Feito em Rust (interface egui), abre quase instantaneamente e lê a biblioteca em segundo plano.

🛠 Como funciona

O Zek Music é escrito em Rust com interface em egui. Você aponta para uma pasta base e o programa varre ela recursivamente em uma thread separada (mantendo a interface sempre responsiva), montando a biblioteca em memória. A pasta é monitorada — quando você cria, renomeia ou remove arquivos, as playlists se atualizam sozinhas. A reprodução roda em thread própria, então dá pra continuar tocando mesmo com a janela minimizada ou fechando.
