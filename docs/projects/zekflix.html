✨ Funcionalidades

🎬

Interface estilo Netflix

Carrosséis horizontais, hero banner, categorias, continue assistindo — tudo familiar.

🤖

Metadados automáticos

Busca pôsteres, sinopses, elenco, avaliações via TMDB/TVDB só pelo nome do arquivo/pasta.

📝

Legendas integradas

Carrega .srt/.ass/.vtt automático, suporte a múltiplas faixas, sincronização, download de legendas.

⏯

Continue de onde parou

Salva posição por episódio/filme, sincroniza entre sessões, marca como assistido.

🖥

Player nativo (mpv)

Usa mpv por baixo — aceleração de hardware, HDR, shaders, atalhos de teclado completos.

📦

AppImage / Instalador

Linux: AppImage única. Windows: instalador NSIS + portable. Auto-update via GitHub Releases.

🛠 Stack técnico

Frontend: HTML/CSS/JS (WebView via Tauri) · Backend: Rust (tauri, serde, reqwest, sqlx) · Player: mpv (JSON IPC) · Metadados: TMDB/TVDB API · DB: SQLite (sqlx) · Distribuição: AppImage (Linux) / NSIS (Windows) · CI: GitHub Actions
