🎬 ZekFlix

Seus filmes e séries locais em interface estilo Netflix

Python PyQt6 mpv AppImage Linux Windows MIT

📥 Instalação

  • Ver última release
  • Linux: AppImage (chmod +x ZekFlix-*.AppImage) + instalar o mpv
  • Windows: instalador .exe ou portátil — o mpv já vem incluído
  • Mint/Ubuntu, se a AppImage não abrir: sudo apt install libfuse2

🔗 Links

  • Repositório no GitHub
  • Reportar bug / Sugerir feature
  • Toca quase tudo: mp4, mkv, avi, mov, webm, ts…

✨ Funcionalidades

📺

Estilo Netflix

Grade escura, capas arredondadas e nota ★ do IMDb — sua coleção local com cara de streaming.

🤖

Metadados automáticos

Capa, título, ano, gênero, elenco, nota e descrição no seu idioma — buscados pelo nome da pasta/arquivo (OMDb).

🌎

15 idiomas

Escolha na primeira abertura (e troque quando quiser no ⚙). Descrições traduzidas uma vez e guardadas em cache.

🗂️

Filmes e séries por pastas

Cada subpasta = um título. Vários arquivos = série; um arquivo = filme. Episódios em ordem natural (ep2 antes de ep10) e toca o próximo ao terminar.

⏱️

Continua de onde parou

Lembra a posição de cada vídeo entre as sessões — perfeito pra séries.

⚡

Cache local

Consulta o OMDb só pra títulos novos; depois abre rapidinho, sem travar a interface.

🔎

Busca

Encontre qualquer título da biblioteca pelo nome.

▶️

Player mpv

Usa o mpv como player: toca a grande maioria dos formatos sem instalar codecs à parte.

🔑 Chave do OMDb (gratuita)

Na primeira abertura o ZekFlix pede uma **chave gratuita do OMDb** (usada só pra buscar capas e descrições). A chave fica salva só no seu computador (~/.config/zekflix/config.json).

  • Acesse omdbapi.com/apikey.aspx → escolha FREE e confirme o e-mail.
  • Cole a chave no ZekFlix (⚙ → Configurar chave do OMDb pra trocar depois).
  • O plano gratuito permite 1.000 consultas por dia — mais que suficiente pra bibliotecas locais.

🛠 Stack técnico

Interface: Python 3 + PyQt6 · Player: mpv (já incluso no Windows; instale no Linux) · Metadados: API OMDb (tradução e cache local em JSON) · Distribuição: AppImage (Linux) / instalador + portátil (Windows) · CI: GitHub Actions
