✨ Funcionalidades

💡

Um clique

Interface mínima: abre, clica no botão, luz acende/apaga. Fecha e fica na bandeja (opcional).

⌨️

Teclados genéricos

Funciona com teclados que usam HID standard (Redragon, Multilaser, generics, etc.).

🚫

Sem terminal

Chega de xset led ou scripts udev. GUI amigável, pronto para uso.

📦

AppImage única

Baixa, roda. Embarca Python + PySide6 + hidapi. Funciona em qualquer distro moderna.

🔧

Detecção automática

Lista dispositivos HID compatíveis, mostra vendor/product ID, permite selecionar qual controlar.

💾

Leve

~15MB, abre em <1s, uso de RAM mínimo. Feito para ficar rodando na bandeja se quiser.

🛠 Como funciona

Usa hidapi (via hid Python package) para enviar comandos HID feature report ao dispositivo. A maioria dos teclados "gamer" genéricos expõe o controle de LED via interface HID padrão (vendor request 0x09 / report ID variável). O app escaneia /dev/hidraw*, identifica teclados conhecidos por VID/PID e envia o pacote de toggle.

⚙️ Requisitos do sistema

  • Linux kernel 5.10+ (suporte hidraw)
  • libhidapi-libusb0 instalado (ex: sudo dnf install hidapi / sudo apt install libhidapi-libusb0)
  • Permissão para acessar /dev/hidraw* (regra udev incluída no repo ou rode via sudo na primeira vez)
