💡 Luz do Teclado

Liga/desliga a luz de fundo (Scroll Lock) no Linux — sem terminal

Rust AppImage .deb .rpm Linux MIT

📦 Instalação

  • Ver última release
  • .deb — Mint/Ubuntu/Debian: sudo apt install ./Luz*.deb
  • .rpm — Fedora/openSUSE: sudo dnf install ./Luz*.rpm
  • AppImage — qualquer distro: chmod +x Luz*.AppImage && ./Luz*.AppImage
  • AppImage no Mint/Ubuntu: sudo apt install libfuse2

⌨️ Linha de comando

  • luz-teclado --on · --off
  • luz-teclado --toggle · --status
  • No AppImage: ./Luz*.AppImage --on
  • Ideal pra atalhos de teclado e scripts.

🛠 Como funciona

No Linux a luz de fundo de muitos teclados é controlada por um arquivo em /sys/class/leds/…::scrolllock/brightness, que só aceita escrita do administrador. O comando manual seria echo 1 | sudo tee .../brightness. O app faz isso por você: acha o LED sozinho (o número inputN muda de máquina pra máquina) e, na primeira execução, pede sua senha uma única vez pra criar a regra /etc/udev/rules.d/99-luz-teclado.rules — que libera a escrita somente no LED do Scroll Lock. Depois disso ele nunca mais pede senha, nem após reiniciar.

⚙️ Requisitos

  • Linux com teclado que expõe o LED do Scroll Lock em /sys/class/leds/
  • AppImage: libfuse2 instalado (Mint/Ubuntu)
  • A senha de administrador é pedida uma única vez, só pra criar a regra udev
