✨ Funcionalidades

🌐

1000+ sites suportados

YouTube, Twitter/X, Instagram, TikTok, Vimeo, Twitch, Reddit, Facebook, SoundCloud, Bandcamp e centenas de outros via yt-dlp.

🎯

Escolha de qualidade

Seleciona resolução (4K, 1080p, 720p...), só áudio (MP3, M4A, OPUS), ou melhor disponível. Preview de formatos antes de baixar.

🔄

Auto-atualização

Verifica nova versão no GitHub ao abrir, baixa e substitui o binário sozinho (Rust). Python version avisa via UI.

📋

Cola e baixa

Detecta URL no clipboard automaticamente, cola com Ctrl+V, Enter para iniciar. Histórico de downloads recentes.

⚙️

Opções avançadas

Cookies do navegador, proxy, rate limit, sponsorblock, embed thumbnail, metadata, capítulos, playlists completas.

📦

Zero dependências

AppImage única (Rust) ou .deb/.rpm (Python) — yt-dlp e ffmpeg embarcados. Roda offline após primeiro uso.

🔀 Duas versões — qual usar?

🦀 Versão Rust (zek-download-windows)

  • Recomendada para novos usuários
  • Binário único, mais rápido, menor
  • Windows: installer NSIS + portable
  • Linux: AppImage nativa
  • Auto-update real (substitui binário)
  • Desenvolvimento ativo

🐍 Versão Python (zek-download)

  • Legacy / manutenção apenas
  • UI em PyQt6
  • Pacotes .deb / .rpm / AppImage
  • Mesmo backend yt-dlp
  • Útil se precisar customizar em Python

🛠 Stack técnico

Rust version: Rust (tauri, reqwest, serde, self_update) + yt-dlp embedded + ffmpeg · Python version: Python 3.10+, PyQt6, yt-dlp, ffmpeg · CI/CD: GitHub Actions (build matrix Linux/Windows, assina artifacts, publica releases)
