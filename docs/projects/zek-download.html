✨ Funcionalidades

🌐

Milhares de sites

YouTube, X/Twitter, Instagram, TikTok, Vimeo, Twitch, Reddit, Facebook, SoundCloud e centenas de outros via yt-dlp.

🎯

Escolha o formato

Selecione resolução (até 4K), só o áudio (MP3/M4A/OPUS) ou o melhor disponível.

📋

Cola e baixa

Detecta a URL no clipboard, atalhos de teclado, fila e histórico de downloads.

🔄

Atualiza sozinho

Verifica nova versão no GitHub e atualiza sem You precisar baixar tudo de novo.

🖥️

Simples e direta

Interface enxuta, sem complicação — pensada pra quem só quer baixar um vídeo ou uma música.

📦

Pronto pra rodar

AppImage/.deb/.rpm no Linux e instalador no Windows. yt-dlp e ffmpeg já inclusos.

🔀 Duas versões — qual usar?

🪟 Versão Rust (zek-download-windows)

  • Reescrita em Rust — mais rápida e leve
  • Foco no Windows (instalador + portátil)
  • Também gera AppImage para Linux
  • Desenvolvimento principal

🐧 Versão Python (zek-download)

  • Versão original em Python
  • Foco no Linux (AppImage/.deb/.rpm)
  • Mesmo motor yt-dlp
  • Útil pra quem quer customizar
🪟 Abrir versão Windows 🐧 Abrir versão Linux
